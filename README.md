# 微课视频工作台 · 技能版

把你电脑里的视频技能汇成一个工作台：**浏览挑选 → 路由 AI 自动选技能 → 大白话全自动剪辑**。

> 核心理念：你不再拖时间轴，而是给 AI 派活。工具替你剪，判断还得你自己来。

---

## 一、这是什么

这是一个 WorkBuddy 技能，也是一个可独立运行的网页应用。它把本机已装的各类视频技能（讲题、口播、动画、国风、剪辑、下载等）整理成一个统一入口，提供三种能力：

| 模式 | 能做什么 |
|------|---------|
| **① 技能浏览** | 按 9 大类筛选、关键词搜索所有视频技能；点卡片看详情、触发词、依赖、输出；一键生成技能提示词 |
| **② 视频路由 AI** | 用大白话描述需求，AI 自动挑最合适的技能 + 推荐工作流 + 可直接用的提示词 |
| **③ 全自动剪辑** | 输入剪辑要求 + 素材文件夹，自动掐头去尾、转场、字幕、BGM、结尾卡，调用本地引擎出片 |

---

## 二、安装

### 方式一：作为 WorkBuddy 技能安装（推荐）

把整个 `micro-course-video-workbench` 文件夹放到你的用户级技能目录：

```
C:\Users\<你的用户名>\.workbuddy\skills\micro-course-video-workbench\
```

放好后重启 WorkBuddy，即可在对话中通过"做个微课""帮我选个视频技能""把这几段视频剪成一条"等说法触发本技能。

> Windows 用户可直接双击包内的 `一键安装.bat`，它会自动复制到位。

### 方式二：只当网页应用用（不装技能）

解压后双击 `index.html` 即可浏览技能、用本地智能推荐。这个方式零配置、不需要 Python，但不能用"直接执行出片"按钮。

## 三、环境要求

| 能力 | 要求 |
|------|------|
| 浏览技能 / 本地推荐 | 仅需浏览器，双击 `index.html` |
| 路由 AI（Qwen 增强） | Python 3.9+，可选环境变量 `DASHSCOPE_API_KEY` |
| 全自动剪辑 | Python 3.9+ + **video-mix-edit 技能**（提供 `scripts/build.py`）+ ffmpeg |
| 本地服务（网页按钮） | Python 3.9+，双击 `启动工作台.bat` |

**全自动剪辑依赖**：本工作台的剪辑能力复用 `video-mix-edit` 技能的本地混剪引擎（全本地 ffmpeg + 语音识别，不上传素材、无需密钥）。请先把该技能装到 `~/.workbuddy/skills/video-mix-edit/`。如你的目录不同，设置环境变量 `VIDEO_MIX_SKILL_DIR` 指向它即可。

**API Key 说明**：本技能**不存储任何密钥**。Qwen 增强需要你自己设置：

```bash
# Windows CMD（临时）
set DASHSCOPE_API_KEY=你的key
# PowerShell（临时）
$env:DASHSCOPE_API_KEY="你的key"
```

不配密钥时，路由 AI 自动用本地关键词匹配，功能不受影响。

## 四、怎么用

### 启动

- **完整功能**：双击 `启动工作台.bat`，浏览器会自动打开 `http://127.0.0.1:8770`。
- **只看展示**：双击 `index.html`。

### 路由 AI

1. 切到「视频路由 AI」标签。
2. 用大白话描述，例如"给初二学生讲光的反射定律，4 分钟，白板手绘风"。
3. 点「智能推荐技能」（本地）或「Qwen 增强」（需密钥+服务）。

**匹配示例：**

| 提示词 | 推荐技能 |
|--------|---------|
| 数学几何题做成讲题微课 | 数学题讲解视频 |
| 讲光的反射定律，白板风 | 物理题讲解视频 |
| 把《静夜思》做成国风短片 | 古诗词 AI 短片 |

命令行：`python video_router.py "你的需求"`

### 全自动剪辑

1. 把录好的原片放进一个文件夹（录废的、卡壳的不用自己剪，原样放入）。
2. 切到「全自动剪辑」标签，填入要求和文件夹路径，例如：
   > 给初二学生的课后复习微课，讲光的反射定律，4 分钟。停顿口误剪掉，加中文字幕字号大，配轻快 BGM 别盖过人声，结尾留 3 秒黑屏。
3. 点「生成剪辑方案」看解析 → 点「直接执行出片」（需启动本地服务）。成片在素材文件夹里。

命令行：

```bash
python auto_edit.py "剪成3分钟竖屏，去掉卡壳，加中文字幕" --dir "素材夹" --dry-run   # 预览
python auto_edit.py "剪成3分钟竖屏，去掉卡壳，加中文字幕" --dir "素材夹"              # 出片
```

**提示词能识别的参数：**

| 你说的 | 理解为 |
|--------|--------|
| 竖屏/9:16、横屏/16:9 | 输出画幅 |
| 3 分钟、每段 6 秒 | 控制时长、掐头去尾 |
| 转场/淡入淡出/黑场 | 段间转场方式 |
| 加字幕/字号大/不要字幕 | 字幕开关与字号 |
| 背景音乐/别盖过人声 | BGM 与音量压低 |
| 结尾留 3 秒 | 结尾卡/黑屏 |

## 五、文件说明

| 文件 | 作用 |
|------|------|
| `SKILL.md` | 技能定义（触发词、工作流、依赖） |
| `index.html` | 网页展示页（单文件，离线可用） |
| `skills_data.js` | 视频技能数据源（网页 + 路由AI 共用） |
| `video_router.py` | 视频路由 AI（Qwen + 本地兜底） |
| `auto_edit.py` | 全自动剪辑（提示词解析 + 调用混剪引擎） |
| `server.py` | 本地服务（托管网页 + API） |
| `启动工作台.bat` | 一键启动（自动找 Python + 开浏览器） |
| `一键安装.bat` | 把技能复制到用户技能目录 |
| `README.md` | 本说明 |

## 六、扩展

- **新增技能**：编辑 `skills_data.js`，在 `skills` 数组追加一条（id/name/category/icon/desc/triggers/keywords/path 等字段），网页和路由 AI 自动生效。
- **数据源格式**：用 `window.SKILLS_DATA = {...}` 而非纯 JSON，是为了让网页双击（file://）也能加载，不受浏览器跨域限制；Python 端正则提取后解析。

## 七、注意事项

1. **成片必须自己从头看一遍**：AI 剪的是节奏，不是内容。学科术语、公式、人名、字幕里的专业名词错得最多，逐句核对。
2. **别让它替你决定讲什么**：能删停顿，删不掉"这个例子学生听不懂"。
3. **学生信息不要进素材**：正脸、姓名、成绩、班级名单一律不传；展示作品先打码或只拍手和作品。
4. **下载素材注意版权**：素材下载类技能仅用于合法教学素材。
